# Tong1122-hub-OpenESRDiscPatcher-

Installation and quick run

This repository currently has simple scaffolding for Python and Node.js to help you get started.

Python
- Create and activate virtualenv:
	- `python3 -m venv .venv`
	- `source .venv/bin/activate`
- Install (if any): `pip install -r requirements.txt`
- Run: `python app.py`

Added Python packages: `requests`, `flask`

Node.js
- Initialize (already done by the setup script): `npm install`
- Run: `npm start` (runs `node index.js`)

Added Node packages: `express`, `axios`, dev: `eslint`
